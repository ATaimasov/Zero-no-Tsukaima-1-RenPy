1. Есть файлы скриптов, которые мы коммитим на гитхаб. и можем подтягивать автоматически
2. А есть медиафайлы. Это аудио, картинки. Они слишком большие для гитхаба. Они отдельным архивом на облаке храниться будут. Без скриптов. 

И если надо будет прям полностью игру обновить, это значит что:
1. обновиться через гитхаб (как щас делаем).
2. скачать архив медиафайлов с облака. и вставить в папку проекта в game (старые папки с этими медиафайлами, если они уже есть - нужно удалить)

Динамические файлы это следующие папки:
- audio
- gui
- images
- video
